A program that writes exactly one Wi-Fi network name — 30 characters — to `/output/entry.txt`, and nothing else.

> Roomba Eloped With The Printer

Two household appliances run away together: the Roomba elopes with the printer, and the owner is left with no clean floors and no printed boarding pass. A whole domestic romance in the few words a passer-by sees in a phone's network list.

Uniqueness was checked against all 2,376 existing submission titles: no entry pairs a Roomba with a printer, and no entry elopes one — the field is full of exes, routers and dogs instead.

## Run it

```sh
node main.ts
```
